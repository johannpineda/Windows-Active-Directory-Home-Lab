# Windows-Active-Directory-Home-Lab
# 🪟 Active Directory Home Lab (Enterprise Simulation)

> A full Windows Server Active Directory environment simulating real-world corporate IT infrastructure, including domain management, Group Policy, user provisioning, and endpoint administration.

---

## 📌 Overview

This project replicates a small enterprise IT environment using Windows Server and multiple Windows client machines. It demonstrates core skills required for IT Support, System Administration, and Security Operations roles.

---

## 🏗️ Architecture

- 1x Windows Server (Domain Controller)
- 2x Windows 10/11 Client Machines
- Virtualized environment (VirtualBox)
- Internal private network

---

## ⚙️ Core Features Implemented

### 🧑‍💼 Active Directory
- Domain creation and management
- Organizational Units (OU structure)
- User and group provisioning
- Role-based access control

### 📜 Group Policy
- Password complexity enforcement
- Login restrictions
- Desktop configuration policies
- USB/device restrictions

### 📁 File Sharing & Permissions
- Shared network drives
- NTFS permission structure
- Role-based folder access

### 💻 Remote Administration
- Remote Desktop Services enabled
- Admin access simulation
- Endpoint management from server
